# game-for-farah

A browser game built with HTML, CSS, and JavaScript.

## Getting started

Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/hamza-kanaan/game-for-farah.git
cd game-for-farah
```

For local development, serving over HTTP avoids browser file:// restrictions:

```bash
npx serve .
```

## Project structure

```
index.html      # game page
css/            # styles
js/             # game logic
assets/         # images, audio
```
